## 🖼️ Adding Your Images

### Required Images

1. **Logo** (`assets/images/logo.png`)
   - PNG with transparent background
   - Recommended: 300x150px
   - Will appear in navigation and footer

2. **Hero Background** (`assets/images/hero-bg.jpg`)
   - High-quality mobile bar setup or drinks photo
   - Recommended: 1920x1080px
   - Homepage full-screen background

3. **About Image** (`assets/images/about-us.jpg`)
   - Professional photo of bar team or setup
   - Recommended: 800x600px

4. **Service Images** (4 images)
   - Full Mobile Bar Services
   - Furniture Cocktail Bar
   - Alcohol-Free Bar
   - Milkshakes & Child-Friendly Bar
   - Recommended: 600x400px each

5. **Event Type Images** (6 images)
   - Wedding, Birthday, Corporate, Private, Umbembeso, Special
   - Recommended: 600x400px each

6. **Gallery Images** (8+ images)
   - Mobile bar setups
   - Bartenders serving guests
   - Colorful drinks
   - Event celebrations
   - Recommended: 800x600px minimum

### Image Tips

✓ Use high-quality, well-lit photographs  
✓ Show actual business setups and events  
✓ Compress images for web (use tinypng.com)  
✓ Keep files under 500KB each  
✓ Use JPG for photos, PNG for logo  
✓ Landscape orientation preferred

## 💬 WhatsApp Integration

The website features **12 WhatsApp contact points**:

1. Navigation "Book Now" button
2. Hero "Book Your Event" button
3. About section enquiry button
4. 4 Service enquiry buttons
5. 6 Event type enquiry buttons
6. Booking form submission
7. Contact section WhatsApp button
8. Floating WhatsApp button

All links direct to: **082 433 5195** (formatted as 27824335195)

### Booking Form

The booking form collects:
- Full Name
- Phone Number
- Event Type
- Event Date
- Event Location
- Number of Guests
- Service Required
- Additional Information

On submission, it:
1. Validates all required fields
2. Formats the information
3. Opens WhatsApp with pre-filled message
4. User sends message to complete booking

**No backend or database required** - all enquiries go directly to WhatsApp.

## 🚀 Deployment

### Option 1: GitHub Pages (Free)

1. Create GitHub account
2. Create repository: "mfundos-mobile-bar"
3. Upload all files
4. Settings → Pages → Enable
5. Live at: `https://username.github.io/mfundos-mobile-bar`

### Option 2: Netlify (Easiest)

1. Go to netlify.com
2. Drag and drop project folder
3. Instant deployment
4. Free subdomain: `yoursite.netlify.app`

### Option 3: Traditional Hosting

1. Upload via FTP or cPanel
2. Place files in `public_html` or `www`
3. Ensure `index.html` is in root

## 📋 Maintenance

### Adding Gallery Images

1. Add images to `assets/images/`
2. In `index.html`, find the gallery section
3. Add new gallery items:

```html
<div class="gallery-item" data-index="X">
    <img src="assets/images/your-image.jpg" alt="Description" loading="lazy">
    <div class="gallery-overlay">
        <i class="fas fa-search-plus"></i>
    </div>
</div>
```

### Updating Services

Edit service cards in the Services section of `index.html`.

### Changing Contact Information

Use Find & Replace in `index.html` to update phone numbers or social media links.
